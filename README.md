### Rayplace 

This is a tiny wallpaper selector I created for macos using Raylib.  
It allows you to easily browse and set wallpapers from a specified folder.

It's just for my personal use so I didn't bundle everything up into a 
nice macos app, but you can compile it yourself using the Makefile. 

Simply run it with 

```
./rayplace /path/to/your/wallpapers
```

and then you can use vim bindings or the arrow keys to navigate 
through the wallpapers.  Press Enter to set the selected wallpaper.
